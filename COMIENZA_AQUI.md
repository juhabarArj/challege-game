## ⚠️ ERRORES COMUNES

### ❌ "git: command not found"
Instala Git desde: https://git-scm.com/

### ❌ "npm: command not found"
Instala Node.js desde: https://nodejs.org/

### ❌ "remote origin already exists"
Ejecuta:
```bash
git remote remove origin
git remote add origin https://github.com/juhabarArj/challege-game.git
```

### ❌ "Port 5173 already in use"
Ejecuta:
```bash
npm run dev -- --port 5174
```

### ❌ No aparece en GitHub Pages
- Espera 5 minutos y recarga
- Ve a: https://github.com/juhabarArj/challege-game/settings/pages
- Verifica que está en rama `gh-pages`
